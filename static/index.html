🔒 Política de privacidade

O que coletamos (somente com seu consentimento)

  • Eventos de uso: quando você abre o app, publica uma foto, curte, comenta, segue, busca ou muda o tema — sem o conteúdo dos textos.
  • Dados do dispositivo: tipo de navegador, tamanho de tela e idioma, para detectar problemas de compatibilidade.
  • Localização aproximada: apenas quando você aceita, arredondada para ~1 km, para entender onde o app é usado.
  • Erros de JavaScript: mensagens de erro para corrigir falhas.

Para que usamos

Melhorar o NearGram: corrigir erros, priorizar funcionalidades e entender o uso em cada região. Nenhum dado é vendido ou compartilhado com terceiros.

Seus direitos (LGPD)

Você pode desativar a coleta a qualquer momento no Perfil → Telemetria. Ao excluir sua conta, todos os dados associados (incluindo telemetria) são apagados.

Contato: admin@neargram.app
